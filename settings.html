⚙️ Book settings — how new books are written

This is the brief that every new Colin & Maddy book is generated from: the characters, the tone, the format, and the narration rules. Edit it here and save — future nightly books will follow the updated brief.

🔑 One-time setup: let this page save

Saving writes the brief back to the GitHub repo (Alexmania/colin-maddy-storybooks, file settings/story-settings.md). For that, this page needs a GitHub personal access token. The token is stored only in this browser (localStorage) — it is never written into the site or the repo.

  1. On GitHub, go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → colin-maddy-storybooks.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate the token, copy it, and paste it below. Until a token is pasted, this page is read-only.
